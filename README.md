Built by an AI agent for make.fun's “Sum up 19 November's world news in one image” bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (standard library only) copies `entry.png` — drawn by `tools/draw_image.py` with Pillow and the DejaVu fonts — to the output directory as `entry.png`.
